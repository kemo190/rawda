# 🌙 روضة — تطبيق إسلامي متكامل

موقع إسلامي هادئ بالعربية فقط، يضم القرآن الكريم (قراءة، تلاوة صوتية، وتفسير ميسّر)، مواقيت الصلاة بعداد حي، أذكار الصباح والمساء، المسبحة الإلكترونية، أسماء الله الحسنى، آية وحديث اليوم، والمفضلة — مبني بـ **٣ ملفات فقط** (`index.html`, `style.css`, `script.js`) بدون أي مكتبات أو Backend.

## ✨ المميزات
- **تطبيق متعدد الصفحات في ٣ ملفات فقط:** صفحة رئيسية هادئة (Home) + صفحات مستقلة للقرآن، المواقيت، الأذكار، الأسماء الحسنى، والمفضلة، عبر نظام توجيه بالهاش (`#home`, `#quran`, `#prayer`, `#adhkar`, `#names`, `#favorites`) يدعم أزرار الرجوع والتقديم في المتصفح.
- **هيدر كبسولة عائم** بتأثير زجاجي وخط `IBM Plex Sans Arabic`، مع **سويتش وضع ليلي/نهاري بأيقونات SVG** وحركة انسيابية.
- **تصميم تحريري عربي هادئ:** هيرو مضغوط يظهر بالكامل في أول شاشة، لوحة آية وحديث اليوم بأسلوب الصفحتين، بوابات منظمة في الصفحة الرئيسية، وزخارف النجمة الثمانية.
- **القرآن الكريم:** الـ ١١٤ سورة، بحث فوري (بدون تشكيل أو بالرقم) وفلتر مكية/مدنية، قراءة بوضع **المصحف** أو **التفسير الميسّر**، ومشغّل تلاوة صوتية آية بآية لـ ٨ قُرّاء.
- **مواقيت الصلاة:** ١٠ مدن (مصر + مكة والمدينة) مع مراعاة المنطقة الزمنية لكل مدينة وعداد تنازلي حي.
- **الأذكار والمسبحة:** ١٤ ذكراً للصباح و١٤ للمساء مع شريط إنجاز، ومسبحة دائرية بـ ٣٣ تسبيحة واهتزاز للموبايل.
- **أسماء الله الحسنى:** الـ ٩٩ اسماً بمعانيها العربية كاملة في بطاقات ثلاثية الأبعاد قابلة للقلب مع بحث فوري.
- **الوضع الليلي والمفضلة والمسبحة:** كلها محفوظة تلقائياً في `localStorage`.

## ▶️ التشغيل محلياً
1. نزّل الفولدر أو اعمل له Clone.
2. اضغط مرتين على `index.html` لفتحه في أي متصفح حديث (يلزم إنترنت لتحميل القرآن والتلاوة والمواقيت والخطوط).

## 🚀 النشر على Vercel
1. ارفع الفولدر على GitHub.
2. افتح https://vercel.com ← **Add New → Project** واستورد المستودع.
3. اختر Framework Preset: **Other** واترك أوامر الـ Build فارغة ثم اضغط **Deploy**.

## 🔌 الـ APIs المستخدمة (مجانية بدون مفتاح)
- القرآن الكريم والتفسير الميسّر: `https://api.alquran.cloud/v1/surah`
- التلاوة الصوتية آية بآية: `https://cdn.islamic.network/quran/audio/`
- مواقيت الصلاة: `https://api.aladhan.com/v1/timingsByCity`

## 🧠 شرح الدوال في `script.js`

| الدالة | الوظيفة |
|---|---|
| `load()` / `save()` | قراءة وحفظ البيانات بأمان في `localStorage` |
| `toArabicDigits(n)` | تحويل الأرقام إلى أرقام عربية (`١٢٣`) |
| `vibrate(pattern)` | تفعيل الاهتزاز على الموبايل عند التسبيح والذكر |
| `dayIndex(length)` | اختيار آية وحديث ثابتَين طوال اليوم ويتغيران يومياً |
| `normalize(text)` | إزالة التشكيل وتوحيد الحروف (`أ/إ/آ → ا`) لتسهيل البحث |
| `showSpinner()` / `showError()` / `toast()` | عرض مؤشر التحميل أو رسالة خطأ مع إعادة المحاولة أو إشعار سريع |
| `getJSON(url)` | جلب البيانات من الـ API والتحقق من نجاح الاستجابة |
| `setTheme(dark)` | تبديل الوضع الليلي والنهاري وحفظ الاختيار |
| `renderHero()` / `copyDaily()` | عرض التحية والتاريخ الهجري والميلادي وآية وحديث اليوم وزر النسخ |
| `loadSurahs()` / `cleanName()` / `surahCard()` | جلب الـ ١١٤ سورة وبناء بطاقاتها |
| `filterSurahs()` / `setSurahFilter()` | البحث الفوري والفلترة بين السور المكية والمدنية |
| `openSurah()` / `renderAyahs()` / `setViewMode()` / `closeModal()` | فتح نافذة السورة وعرض المصحف أو التفسير الميسّر |
| `audioUrl()` / `playAyah()` / `highlightAyah()` / `togglePlay()` / `stopAudio()` | تشغيل التلاوة الصوتية آية بآية مع التظليل والانتقال التلقائي |
| `toggleFavorite()` / `renderFavorites()` / `handleGridClick()` | حفظ وإزالة السور المفضلة والتعامل مع نقرات البطاقات |
| `fillSelects()` / `loadPrayerTimes()` | تعبئة قوائم المدن والقُرّاء وجلب مواقيت الصلاة |
| `toSeconds()` / `format12()` / `nowSeconds()` / `getNextPrayer()` | حساب الصلاة القادمة والوقت المتبقي حسب التوقيت المحلي للمدينة |
| `renderPrayers()` / `updateCountdown()` | عرض بطاقات الصلوات الخمس وتحديث العداد كل ثانية |
| `setAdhkarType()` / `renderAdhkar()` / `handleDhikrClick()` | التبديل بين أذكار الصباح والمساء والعدّ وإعادة الضبط وشريط الإنجاز |
| `tasbihTap()` / `updateTasbih()` | تحديث عداد المسبحة الدائرية وتغيير الذكر كل ٣٣ تسبيحة |
| `renderNames()` | عرض وبحث أسماء الله الحسنى الـ ٩٩ ومعانيها العربية |
| `showPage()` / `onScroll()` | التبديل بين الصفحات عبر رابط الهاش وتحديث شريط التقدم وزر العودة للأعلى |
| `init()` | نقطة البداية لتشغيل كل أجزاء التطبيق |
