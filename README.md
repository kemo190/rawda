# 🌙 روضة — تطبيق إسلامي متكامل (PWA)

تطبيق ويب إسلامي هادئ بالعربية بالكامل، قابل للتثبيت على الموبايل كتطبيق (**PWA**)، يضم القرآن الكريم (قراءة، تلاوة صوتية لـ ٨ قرّاء، وتفسير ميسّر)، مواقيت الصلاة بعدّاد حي، أذكار الصباح والمساء، المسبحة الإلكترونية، أسماء الله الحسنى، آية وحديث اليوم، والمفضلة — بدون أي Frameworks أو Backend.

> 📘 **لفريق العمل:** راجع ملف [شرح-المشروع.md](شرح-المشروع.md) للحصول على شرح مبسّط كامل للمشروع + ٢٠ سؤالاً متوقعاً للمناقشة + توزيع الأدوار على الفريق.

## ✨ المميزات
- **تطبيق متعدد الصفحات (SPA):** صفحة رئيسية (Home) + صفحات مستقلة للقرآن، المواقيت، الأذكار، الأسماء الحسنى، والمفضلة عبر Hash Routing (`#home`, `#quran`, `#prayer`, `#adhkar`, `#names`, `#favorites`).
- **قابل للتثبيت على الموبايل (PWA):** يحتوي على `manifest.json` + `sw.js` (Service Worker) + أيقونات التطبيق + زر **«تثبيت التطبيق»** في الصفحة الرئيسية.
- **القرآن الكريم وقارئ المصحف:** ١١٤ سورة، بحث بدون تشكيل، فلتر مكية/مدنية، شريط «متابعة آخر قراءة»، وصول سريع لأشهر السور، قراءة بالمصحف أو التفسير الميسّر، تكبير/تصغير الخط، ومشغّل تلاوة صوتية آية بآية لـ ٨ قرّاء مع زر تكرار الآية.
- **مواقيت الصلاة:** ١٠ مدن (مصر + مكة والمدينة) مع مراعاة المنطقة الزمنية لكل مدينة وعدّاد تنازلي حي.
- **الأذكار والمسبحة:** ١٤ ذكراً للصباح و١٤ للمساء مع شريط إنجاز، ومسبحة بحلقة ٣٣ واهتزاز للموبايل.
- **أسماء الله الحسنى:** الـ ٩٩ اسماً بمعانيها العربية كاملة في بطاقات ثلاثية الأبعاد قابلة للقلب مع بحث فوري.
- **الوضع الليلي والمفضلة وحفظ الإعدادات:** محفوظة تلقائياً في `localStorage`.

## 📁 ملفات المشروع
- `index.html` — هيكل الصفحات الـ ٦ والقارئ والفوتر.
- `style.css` — التنسيق والألوان والوضع الليلي والتجاوب مع الموبايل.
- `script.js` — منطق التطبيق والـ APIs والتلاوة ونظام الصفحات وPWA (مشروح بالتعليقات العربية).
- `manifest.json` — بيانات تطبيق الويب التقدمي (PWA).
- `sw.js` — Service Worker للتثبيت وحفظ الملفات الأساسية في الكاش.
- `icon-192.png` / `icon-512.png` — أيقونات التطبيق.
- `شرح-المشروع.md` — دليل الشرح والمناقشة الشامل للفريق.

## ▶️ التشغيل محلياً
1. نزّل الفولدر أو اعمل له Clone.
2. افتح `index.html` في أي متصفح حديث (للتثبيت كـ PWA افتحه عبر HTTPS مثل GitHub Pages أو Vercel).

## 🚀 النشر
- **GitHub Pages:** من إعدادات الريبو `Settings → Pages → Branch: main → Save`.
- **Vercel:** استورد الريبو من https://vercel.com/new واختر Framework Preset: **Other** واضغط **Deploy**.

## 🔌 الـ APIs المستخدمة (مجانية بدون مفتاح)
- القرآن الكريم والتفسير الميسّر: `https://api.alquran.cloud/v1/surah`
- التلاوة الصوتية آية بآية: `https://cdn.islamic.network/quran/audio/`
- مواقيت الصلاة: `https://api.aladhan.com/v1/timingsByCity`
